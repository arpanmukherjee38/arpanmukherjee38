### 🧑‍💻 About Me

I work at the intersection of **Embodied AI, Robotics Control, and Production LLM Engineering**—bridging physical hardware and simulation with scalable software pipelines.

- 🔭 **Currently building:** An end-to-end **Language-Conditioned Manipulation Policy** in `MuJoCo` & `LeRobot` with a classical joint-limit safety filter and quantized `ONNX` edge deployment.
- 🌱 **Exploring:** Agentic orchestration (`LangGraph`, `MCP`), hybrid retrieval pipelines, and Vision-Language-Action (VLA) models.
- 🏆 **Highlights:** Merged upstream performance PR in **scikit-learn** (`+15%` throughput) and published peer-reviewed robotics research at **TSSC 2026**.
- ⚡ **Focus areas:** Robot Learning • Multi-Agent Workflows • Embedded C++/ESP32 • Edge Inference Optimization
